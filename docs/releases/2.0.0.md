# Reference for Zotero 2.0.0 发布说明

`2.0.0` 把 Reference for Zotero 从 References / Citations 浏览工具扩展为完整的论文关系阅读入口：插件可以自动补全摘要、生成并缓存 AI 阅读建议、从正文引用编号跳转到 Reference 条目，并在统一设置页中管理下载、OpenAlex 和推荐模型。

## 核心功能

### AI 阅读建议

AI 推荐会使用当前论文的完整 MinerU Markdown，以及当时已经取得非空 Abstract 的 References 和 Citations，一次性生成完整的“优先看 / 可选看”结果。

- 推荐严格覆盖本次送入模型的全部候选，“优先看”最多五篇，其余进入“可选看”。
- 每篇显示 Reference / Citation 来源和一句与当前论文直接相关的理由，不显示模型分数。
- 模型每生成一条完整建议，Reader 就立即显示，并更新“已生成 X / Y 篇”；最终结果仍需通过完整 JSON 校验。
- 完整结果按当前论文写入 `recommendation.json`。论文、正文、候选摘要或活动模型未变化时，再次打开会直接恢复，不重复调用模型。
- 推荐论文支持普通左键详情、`Ctrl + 左键`落地页、右键菜单、年份显示和划词翻译。

对应需求：[Issue #54](https://github.com/Woif-sha/reference-for-zotro/issues/54)、[Issue #56](https://github.com/Woif-sha/reference-for-zotro/issues/56)、[Issue #57](https://github.com/Woif-sha/reference-for-zotro/issues/57)、[Issue #58](https://github.com/Woif-sha/reference-for-zotro/issues/58)。交互整合见 [PR #66](https://github.com/Woif-sha/reference-for-zotro/pull/66)。

### 自动摘要与 OpenAlex

- 打开相关论文区域后自动加载前 10 篇 Citations，并依次补全 References 与已加载 Citations 的缺失摘要。
- OpenAlex 与 Semantic Scholar 摘要按 DOI 写入当前论文缓存目录的 `abstract.json`，下次打开直接恢复。
- 蓝色、斜体且带蓝色下划线的题名表示摘要已就绪；普通蓝色题名表示仍在补全。
- Preferences 支持可选 OpenAlex API Key，并可测试连接、查看当日剩余余额。

实现和修复见 [PR #63](https://github.com/Woif-sha/reference-for-zotro/pull/63)、[PR #64](https://github.com/Woif-sha/reference-for-zotro/pull/64)、[PR #65](https://github.com/Woif-sha/reference-for-zotro/pull/65)。

### Reader 导航与交互

- 在 PDF 正文中对数字引用执行 `Ctrl + 右键`，插件会打开 References、定位并高亮对应条目；支持单个编号、组合、区间和跨文本层片段。
- Abstract 中受支持的行内 LaTeX 会转换为普通可读文本。
- Reader“相关论文”标题栏新增设置按钮，可以直接打开插件 Preferences。

实现和修复见 [PR #59](https://github.com/Woif-sha/reference-for-zotro/pull/59)、[PR #60](https://github.com/Woif-sha/reference-for-zotro/pull/60)、[PR #62](https://github.com/Woif-sha/reference-for-zotro/pull/62)。

### 设置与下载

- 下载目录和 ScanSci Cache 路径必须分别通过原生目录选择器显式配置。
- 推荐模型使用服务商卡片管理，可选择 Codex Auth 或 HTTPS OpenAI Compatible，并在保存前测试连接。
- 下载继续限制为已确认身份的论文和经过审计的 legal-only 路由；当前启用 arXiv 与 PMC，机构浏览器路由保持禁用。
- 插件只自动探测兼容运行时，不创建 Python 环境、不安装依赖、不修改全局 pip 配置。

设置一致性和路径修复见 [PR #61](https://github.com/Woif-sha/reference-for-zotro/pull/61)，Reader 快捷入口见 [PR #62](https://github.com/Woif-sha/reference-for-zotro/pull/62)。

## 安装与升级

1. 从 [GitHub Releases](https://github.com/Woif-sha/reference-for-zotro/releases/latest) 下载 `reference-for-zotero.xpi`。
2. 在 Zotero 中打开“工具 → 插件”，选择“从文件安装插件”。
3. 安装完成后完全退出并重新启动 Zotero。
4. 展开 Reader 的“相关论文”，点击标题栏设置按钮，按需配置下载路径、OpenAlex Key 和推荐模型。

从 `1.x` 升级会保留现有 Zotero 插件设置和逐论文 literature cache。AI 推荐和自动摘要使用现有 `reference-for-zotero-cache/v2/papers` 命名空间中的独立文件，不修改 Zotero 条目字段或 MinerU 文件；既有的 Canonical Reference 规范化仍可能按其合同同步当前附件的 MinerU `full.md`、`content_list.json` 和 `manifest.json`。

## 发布验证

正式发布必须通过 `npm run verify`，覆盖 TypeScript 和 Python 自动化测试、类型检查、ESLint、Prettier、生产构建和 XPI 内容审计。发布工作流还会核对 `package.json`、`v2.0.0` 标签、Release 标题和产物版本一致性。
