# Security policy

## Supported versions

Security fixes are provided for the latest stable `2.x` release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, contact the repository owner through GitHub without publishing credentials, private library data or a working exploit in a public issue.

Include the affected plugin version, Zotero version, impact, reproduction conditions and the smallest safe proof of concept. For model or OpenAlex issues, identify the provider type without including API keys, Codex tokens, `auth.json` contents or private paper text. Public disclosure should wait until a fix or mitigation is available.
